# Athkar Bot (@Najd_Are)

بوت يغرد تلقائياً على X بتوقيت الرياض:

- تذكير كل صلاة وقت الأذان (طريقة أم القرى)
- أذكار الصباح بعد الفجر، وأذكار المساء بعد العصر (مع صورة)
- صلاة الضحى، وتذكير سورة الملك الساعة 10 الليل (مع صورة)، والوتر بالثلث الأخير من الليل
- سنن الجمعة صباح الجمعة، والصلاة على النبي ﷺ مغرب الخميس
- تذكير صيام الاثنين والخميس، والأيام البيض (تقويم أم القرى)

كل النصوص في `athkar/texts.py`، ونص الآيات يُسحب من نص المصحف (Tanzil) عبر `tools/build_verses.py`.

البوت ينشر فعلياً. لإيقاف النشر مؤقتاً: أضف متغير المستودع `DRY_RUN` بقيمة `true`.
